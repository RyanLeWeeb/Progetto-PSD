Specifica Sintattica e Semantica

- Richiesta *creaListaRichiesta() -> r
    - Post r = NULL; r è una lista di richieste, ed è inizializzata a NULL, cioè è vuota.

- void aggiornaListaRichiesta(Richiesta *l)
    - Pre: l è una lista di richieste in cui è presente almeno una richiesta.
    - Post: come side-effect, il file di testo "Richiesta.txt" 
            viene ri-scritto con tutte le richieste presenti nella lista data.
